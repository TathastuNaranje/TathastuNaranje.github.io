# Tathastu Naranje — Personal Website

🌐 **Live site:** [tathastunaranje.github.io](https://tathastunaranje.github.io)

This repository hosts the source code for my personal website — the digital headquarters of my work as a **Renaissance Consultant**: a Market Intelligence Consultant, the author of *Three Astral*, and a musician.

## What you'll find on the site

The site is structured as an editorial publication, with three primary sections:

1. **The Consultant** — Market intelligence work for global procurement teams. Vendor analysis, supplier landscapes, and category strategy.
2. **The Storyteller** — *Three Astral*, my debut speculative fiction novel about a young man whose seizures transport him between Earth and a mystical parallel planet. Available on Amazon, Books-A-Million, Thriftbooks, Wissen, and Google Books.
3. **The Creative Spirit** — Music production, guitar and keyboard practice, and explorations of AI-assisted composition.

## Design philosophy

The site is designed in a minimalist editorial aesthetic — drawing from high-end print publications and museum catalogs. High-contrast serif typography, restrained cream and charcoal palette, generous whitespace, and a built-in light/dark theme toggle for accessibility.

## Stack

A single-file static site (`index.html`) deployed via GitHub Pages. No frameworks, no build step — just hand-crafted HTML and CSS.
